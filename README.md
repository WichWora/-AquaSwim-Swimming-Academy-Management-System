# AquaSwim-Swimming-Academy-Management-System
AquaSwimming Academy – Swimming Management System is a full-stack, mobile-responsive web application designed to streamline swimming academy operations, featuring multi-role authentication, class scheduling, online enrollment, Stripe payments, attendance tracking, and financial analytics. Developed for BMIT2023 Web and Mobile Systems at TARUMT.

Detailed Description
**Overview**
The Swimming Management System (AquaSwimming Academy) is an all-in-one management platform built to automate student admissions, class timetables, instructor assignments, billing, and business reporting for swimming centers.

**Key Features**
1. Security & Account Management:
Multi-role access control (Admin, Manager, Coach, Student) with bcrypt password hashing, email OTP verification, password recovery, login lockout protection, and profile photo editing.

2. Program & Class Scheduling:
Full CRUD operations for skill levels (Beginner to Competitive) and age groups, coach assignments, pool capacity management, interactive calendar views, and automated waitlist enrollment.

4. Enrollment & Payment Processing:
Online checkout with emergency contact and medical waiver collection, Stripe API payment integration, package and family discounts, automated email/SMS confirmations, and downloadable PDF invoices and e-receipts.

6. Coach & Student Portals:
Mobile-friendly attendance tracking for coaches, alongside student dashboards featuring registered schedules, skill progression tracking, achievement badges, and digital certificates.

8. Analytics, Reviews & Localization:
Real-time financial and enrollment dashboards with Excel/CSV export, student/parent review and rating systems, Google Maps pool location integration, and instant English-to-Malay page translation.
